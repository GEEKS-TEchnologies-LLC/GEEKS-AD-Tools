CSV Import & AD Comparison

Upload a CSV file containing employee data. The system will compare this with your Active Directory users.
Expected CSV Format:
Column Name Description Required
Employee ID or employee_id or ID Employee identification number Yes
Name or name or Full Name Employee's full name Yes
Email or email Employee's email address No
Default Jobs (HR) or Job Title Employee's job title No
What This Tool Does:
  • Matches CSV employees with AD users by name or employee ID
  • Updates employee IDs and job titles in AD for matched users
  • Generates two lists: users in CSV vs users not in CSV
  • Bulk operations: disable and move users not in CSV
Sample CSV Format
Employee Id,First Name,Last Name,Default Jobs (HR)
EMP001,John,Doe,Software Engineer
EMP002,Jane,Smith,Project Manager
EMP003,Bob,Johnson,System Administrator
EMP004,Alice,Brown,Network Engineer
EMP005,Charlie,Wilson,Database Administrator
Important Notes
  • CSV must be UTF-8 encoded
  • Column names are case-insensitive
  • Employee ID and Name are required
  • Email is optional but recommended
  • Large files may take time to process
