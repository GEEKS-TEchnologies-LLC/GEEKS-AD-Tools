Connection Information
  • LDAP: Use port 389 for standard LDAP connections
  • LDAPS: Use port 636 for secure LDAP connections
  • Bind DN: The distinguished name of the user account for binding
  • Base DN: The root distinguished name of your Active Directory (e.g., DC=yourdomain,DC=com)
  • Primary Users OU: Where your USER ACCOUNTS are located (e.g., OU=Users,OU=Company,DC=yourdomain,DC=com)
  • Groups OU: Where your SECURITY GROUPS are located (separate from users)
